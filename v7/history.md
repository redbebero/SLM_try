# v7 실험 기록

v7에서는 자모를 여러 출력 트랙으로 직접 생성하던 이전 구조가 새로운 표현의 질문을 잘 처리하지 못하고, 학습 손실이 낮아져도 실제 자유 생성에서 같은 음절을 반복하던 문제를 해결하고자 했다. 원인을 모델 크기만의 문제로 단정하지 않고, 한글을 완성형 문자가 아닌 토큰 단위로 학습하는 약 5천만 파라미터의 causal Transformer를 처음부터 구현했다. 6GB VRAM 환경을 고려해 16,384개 Unigram 토크나이저, 8개 Transformer 블록, RMSNorm·RoPE·가중치 공유 구조를 사용하고, 실제 학습 전에 토크나이저의 한국어 round-trip과 한 배치 과적합을 검사했다. 토크나이저 검사는 통과했고 한 배치 손실도 5.1369에서 3.1287로 감소하여 기본 구현과 데이터 정렬이 작동함을 확인했다.

작은 말뭉치에서 1,000단계 사전학습을 실행한 뒤, 더 많은 한국어 QA·추론 데이터를 합친 확장 corpus를 준비했다. 그러나 준비한 데이터가 실제로는 약 510만 개의 고유 학습 토큰에 불과한데 이를 1억 토큰 규모처럼 취급하면 반복 학습과 과적합을 성능 향상으로 오해할 수 있다고 판단했다. 따라서 데이터 규모를 부풀려 성공으로 기록하지 않고, 학습 토큰 수를 명시한 뒤 확장 학습을 중단하고 검증 가능한 작은 실험으로 범위를 제한했다.

대화 데이터로 assistant-only SFT를 수행한 결과 `chat.pt`는 다섯 개의 고정 질문과 한 개의 다중턴 질문에서 한국어 문장을 생성하고 `<|end|>`에서 종료했다. 하지만 학습을 더 진행한 `chat_final.pt`에서는 질문 내용과 관계없이 “안녕하세요”를 반복하는 모드 붕괴가 나타났다. 이를 통해 학습 손실이 감소하거나 문장이 자연스러워 보이는 것만으로 대화 능력을 판단할 수 없음을 확인했다. 현재는 더 긴 학습을 성공으로 채택하지 않고, 고정 질문·다중턴 질문·종료 토큰·반복 여부를 함께 검사하는 평가를 기준으로 삼았다. v7의 현재 결론은 모델을 무조건 키우는 것이 아니라, 데이터의 실제 규모를 정확히 측정하고 학습 단계별 출력 변화를 비교하여 과적합과 일반화를 구분해야 한다는 것이다.
